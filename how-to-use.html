MY CODE 사용 흐름

이미지 한 장을 올리면 웹에서 바로 사용할 수 있는 이미지 주소와 HTML, CSS 코드가 함께 만들어집니다.

JPG · PNG · WEBP · GIF파일당 최대 10MB무료 플랜 하루 1회

01 / UPLOAD

이미지를 올립니다.

메인 화면의 업로드 영역을 클릭하거나 이미지를 끌어놓으세요. 여러 장을 선택해도 한 번의 업로드 동작으로 처리됩니다.

＋
이미지 선택클릭하거나 여기에 파일을 끌어놓으세요.
10MB 이하
10MB를 넘는 이미지는 업로드되지 않으며 무료 사용 횟수도 차감되지 않습니다.

02 / IMAGE URL

이미지 주소를 그대로 사용합니다.

아임웹, 카페24, CMS, 마크다운처럼 이미지 주소만 필요한 곳에는 IMAGE URL을 복사해서 붙여넣으면 됩니다.

IMAGE URL
https://img.mycode.kr/example/hero-image.webp

03 / HTML

HTML 이미지 태그로 붙여넣습니다.

HTML 편집 영역이나 코드 위젯에는 자동 생성된 img 태그를 그대로 사용할 수 있습니다.

HTML
<img src="https://img.mycode.kr/example/hero-image.webp" alt="">
IMWEB

아임웹 코드 위젯

HTML 코드 위젯에 생성된 img 태그를 붙여넣고 저장합니다.

CAFE24

카페24 HTML 영역

상세페이지나 게시판 HTML 편집 화면에 그대로 붙여넣습니다.

04 / CSS BACKGROUND

배경 이미지에는 CSS 코드를 사용합니다.

섹션 히어로, 배너, 카드 배경처럼 CSS로 이미지를 넣을 때는 background-image 코드를 복사하세요.

CSS
background-image: url("https://img.mycode.kr/example/hero-image.webp");

05 / FREE USE

하루 1회 무료로 바로 사용합니다.

무료 플랜은 하루 1회 이미지 코드 생성 기능을 사용할 수 있습니다. 로그인하면 생성한 이미지와 코드를 My Cloud에 저장하고 계정에서 다시 관리할 수 있습니다.

DAILY FREE

매일 1회 무료

날짜가 바뀌면 무료 사용 횟수가 다시 열립니다.

SIGNED IN

My Cloud 연결

로그인하면 생성 자산을 저장하고 검색 · 복사 · 재사용할 수 있습니다.

06 / MY CLOUD

로그인 후에는 작업 자산을 다시 꺼내 씁니다.

업로드한 이미지와 생성된 URL·HTML·CSS 코드를 My Cloud에서 검색하고 다시 복사할 수 있습니다.

SAVE

자동 저장

로그인 상태에서 생성한 자산은 My Cloud와 연결됩니다.

REUSE

검색 · 복사 · 재사용

파일명으로 찾고 URL·HTML·CSS를 다시 복사합니다.
