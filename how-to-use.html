HOW TO USE

올리고, 복사하고,
필요한 곳에 붙여넣으세요.

MY CODE는 별도 설정 없이 이미지 업로드부터 웹 코드 사용까지 가장 짧은 흐름으로 사용할 수 있습니다.

4 STEPS

사용 방법은 간단합니다.

메인에서 바로 시작할 수 있고, 로그인하면 생성한 자산을 My Cloud에서 다시 사용할 수 있습니다.

01 / UPLOAD

이미지를 올립니다.

메인 화면의 업로드 영역에 JPG, PNG, WebP, GIF 이미지를 끌어놓거나 클릭해서 선택합니다. 파일당 최대 10MB입니다.

02 / GENERATE

코드가 자동으로 만들어집니다.

업로드가 끝나면 IMAGE URL, HTML img 태그, CSS background-image 코드가 한 번에 생성됩니다.

03 / COPY

필요한 코드를 복사합니다.

홈페이지 이미지에는 URL 또는 HTML을, 배경 이미지에는 CSS 코드를 복사해서 사용하면 됩니다.

WHERE TO USE

이런 작업에 바로 사용할 수 있습니다.

HTML

일반 웹사이트

생성된 img 태그를 HTML 코드에 그대로 붙여넣습니다.

BUILDER

아임웹 · 카페24

코드 위젯이나 HTML 편집 영역에서 생성된 이미지 URL과 코드를 사용합니다.

CSS

배경 이미지

배너나 섹션 배경에는 CSS background-image 코드를 그대로 사용할 수 있습니다.
