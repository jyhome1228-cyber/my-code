HOW IT WORKS

업로드하면 바로 사용할 수 있습니다.

복잡한 설정이나 저장소 관리 없이 이미지 한 장부터 바로 시작할 수 있습니다.

01 / UPLOAD

이미지를 올립니다.

JPG, PNG, WEBP, GIF를 드래그하거나 여러 장을 한 번에 선택합니다.

02 / GENERATE

코드가 만들어집니다.

IMAGE URL, HTML img 태그, CSS background 코드가 자동으로 생성됩니다.

03 / COPY

복사해서 바로 사용합니다.

아임웹, 카페24, GitHub, 일반 HTML 등 필요한 곳에 그대로 붙여넣습니다.

MY CLOUD

로그인하면 작업 자산이 남습니다.

한 번 만든 이미지와 코드를 다시 찾기 위해 파일을 새로 올릴 필요가 없습니다.

SAVE

자동 저장

로그인한 상태에서 생성한 이미지와 코드가 My Cloud에 자동 저장됩니다.

SEARCH

파일명 검색

저장한 이미지가 많아져도 파일명으로 빠르게 찾을 수 있습니다.

REUSE

다시 복사

URL, HTML, CSS를 언제든 다시 복사해 다음 프로젝트에서 재사용합니다.
