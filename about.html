ABOUT MY CODE

이미지 작업을 더 짧게,
웹 작업은 더 단순하게.

MY CODE는 이미지를 올리고, 웹에서 쓸 주소와 코드를 만들고, 다시 찾는 과정을 하나로 연결합니다.

WHY WE BUILT IT

반복되는 이미지 작업을 줄이기 위해 만들었습니다.

이미지를 저장할 곳을 찾고, 주소를 복사하고, HTML과 CSS 코드를 다시 만드는 작은 반복을 줄이는 것이 MY CODE의 시작입니다.

01 / SIMPLE

바로 시작

별도 설정 없이 이미지 한 장부터 바로 업로드하고 사용할 수 있습니다.

02 / PRACTICAL

웹에서 바로 사용

IMAGE URL, HTML img 태그, CSS background 코드를 한 번에 제공합니다.

03 / REUSABLE

다시 꺼내 쓰기

로그인하면 생성한 이미지와 코드를 My Cloud에 저장하고 다시 사용할 수 있습니다.

FOR WEB MAKERS

디자이너와 웹 작업자를 위한 도구입니다.

아임웹, 카페24, GitHub Pages, 일반 HTML 등 이미지를 코드로 연결해야 하는 작업에서 빠르게 사용할 수 있도록 설계했습니다.
